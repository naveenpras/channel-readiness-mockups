Cloudinary DAM console

Channel Readiness

Interactive mockups for linking SKUs to their assets, checking those assets against each sales channel's listing requirements, and generating compliant variations in bulk.

Design mockups, not production code — they run entirely in the browser with no build step and no backend.

Screens

Channel Readiness

The main app: readiness dashboard, product table, channel configuration, the per-SKU compliance matrix, the asset picker, and the bulk variation flow.

SKU Details

One product in depth — its original captures, the per-channel variations built from them, and why each one passes or fails.

SKU Channel Setup Flow

The three-step wizard for adding a new SKU, linking its assets and picking the channels to run.

Readiness Banner Options

Layout options for the dashboard banner that introduces the flow.
SKU Details renders whichever product it is handed via a ?sku= parameter, for example ?sku=FTW-RUN-60026. Clicking into a product from the main app links through with it set.
