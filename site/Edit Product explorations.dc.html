Edit products
Two ways to manage a product after it exists. Both show where every value came from (read from a file name, already on the asset, or typed by you), flag values that disagree, and treat sequence and label as per-asset fields next to the product-level ASIN, EAN and description. Every frame is interactive.
A Product page: details and assets side by side Open page
A full page you reach from a product row. Everything is visible at once: product fields on the left, the ordered asset list on the right. Best for working through one product carefully. Each field says where its value came from, and when two assets carry different values you pick one in place. Reorder with the arrows, set labels per asset, and read file names for assets added later.
B Drawer from the Products list: details, assets, file names Open page
A drawer that opens over the Products list, so a quick fix to one SKU keeps your place in the list. Three tabs split the job. Details holds the product fields with suggestion chips for values we found. Assets is a compact list with bulk label and remove. File names shows how the pattern read every file and lets you read the names again, with a preview of what would change and a switch to keep what you edited.
A in context Product page: Readiness and Details and assets in one page Open page
Clicking a row on Products opens one product page in the same shell as Product details. The title area is shared. The Readiness tab keeps what Product details has today (the red missing banner, the blue re-run banner, Originals, Asset variations). The Details and assets tab is Option A. The two tabs read the same state: a label set on an asset fills that channel slot on Readiness straight away, and a missing EAN on Readiness is a button that lands on the EAN field. One save bar serves both tabs. Saving a change to the originals brings back the existing re-run prompt.
1. Row opens the page on Readiness. EAN and two slots are missing.
2. “Add EAN” lands on the field. The ASIN conflict is resolved in place.
3. Edits made. One save bar, whichever tab you are on.
4. Saved. Back on Readiness the slots are filled and the re-run prompt appears.
Product details, extended Same Product details screen, with metadata and sequence added Open page
Nothing on the existing screen moves or changes. Two things are added, both in the screen's own section style. A “Product metadata” section sits above Originals: ASIN, EAN and description, each saying where its value came from, with a picker when assets disagree and a missing flag for fields a channel requires. On Originals, every tile gets a sequence number, its file name, and left and right arrows, with “Sort by file name” and “Reset to file names” in the section header. A save bar appears only when something changed. Saving a new sequence offers the screen's existing “Run tool again” step. The label chips and the three-dot menu are untouched.
Direction Product details stays as it is. A separate Edit product screen does the editing. Open page
Product details still shows the originals and every channel variation, and gets one new button next to the title: “Edit product”. That opens a full screen with its own job. On the left you see and edit the product metadata (ASIN, EAN, description) with where each value came from. On the right you add and remove assets, change the sequence, and manage labels, using the same label chips as Product details. One save bar serves the whole screen. After saving, “Back to Product details” returns you, and if the originals changed the screen's existing re-run prompt is the next step. Frame 1 is the Product details screen with the new button. Frames 2 to 4 are the Edit product screen in three states.
1. Product details, unchanged except for the Edit product button.
2. Edit product opens with the metadata and the assets in sequence. The EAN is missing and two ASINs disagree.
3. A complete product made from file names, with six assets.
4. A product created by hand. No file name pattern, so every value is existing or typed.
