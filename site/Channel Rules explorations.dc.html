Channel rules for public and custom channels
Two options built on the current Public channel page, with the same header, cards and lock icons. Both cover the three cases: a public channel, a custom channel with the same settings for every product image, and a custom channel with settings by position.
Product images
Model shots and plain product shots get a background, frame and dimensions. Each of the three can be turned off when the originals already meet the channel. Feature callouts, annotated product images, lifestyle shots and infographics are left alone. The file name is a free pattern with tokens for the customer’s metadata and the position, for example {asin}.pt{position}.jpg. Any text can go between the tokens. A lifestyle image can be created when the product has none.
Video
A product video is delivered in the channel’s format, and one can be created when missing. A VTT file is used when the product has one, and created when it does not. File names use the same kind of pattern, for example {asin}.video.mp4 and {asin}.vtt.
Public and custom
On a public channel the values are set by the channel and locked. The customer can turn each one off, and the file name pattern is always theirs to edit. A custom channel can set every value. By position, images 1 to n get their own settings, and all other images share one set.
A A table of settings by position Open page
Settings are rows, one per setting, on the same page as the existing public channel. By position, the rows become a table: one line per image position and a last line for all other images. Each cell has its own switch and value.
Works well when
The customer wants to compare positions. The table shows at a glance that image 1 gets a grey background and images 2 and later get white, and file names are visible side by side.
Watch out for
The table is wide. Dimensions and file name need about 1,100 px, so smaller screens scroll sideways.

B Setting cards, one position at a time Open page
Settings are four cards: background, frame, dimensions and file name. By position, tabs run along the top (Image 1, Image 2, Image 3, All other images) and the same four cards edit the tab you are on. A stepper sets how many images have their own settings.
Works well when
The customer thinks about one image at a time, or has many positions. Each card has room for its explanation, and nothing needs sideways scrolling.
Watch out for
Comparing positions means switching tabs. A summary of what each position gets would help if customers set more than three or four.

Public channels: product shots and additional images
Images now come in two kinds, and the page says so up front. Product shots are studio images of the product. We change their background, size, framing and quality to match the channel, and name them with the customer’s identifier and tag. Additional images (callouts, lifestyle, product in use, annotated, packaging, info panels) come from the customer’s creative team. We never change what is in them. We fit them to the channel size, by scaling or padding, and name them in sequence. Public channel values stay locked. Customers edit the file name patterns, the numbering, the face crop and lifestyle creation.
A Stacked sections with a file name table Open page
Two explainer cards, then a Product shots section, an Additional images section, and a table of the file names a sample product would get. Each section holds its locked rules and its editable settings.
Works well when
The customer reads top to bottom once and sees the full rule set. The file name table at the bottom answers “what will my files be called” without switching anything.
Watch out for
The page is long. Changing a pattern at the top means scrolling down to see the result.
Use the Mockup view bar to switch between Amazon, Walmart and Target. Edit a file name pattern to see the sample names change.
B Tabs with a live preview Open page
The same two explainer cards, then two tabs, Product shots and Additional images, with settings on the left. A sticky panel on the right lists a sample product’s images with their final file names and what happens to each. A warning appears if two files get the same name.
Works well when
Pattern editing is the hard part, and the preview updates as the customer types. Each tab stays short.
Watch out for
The preview takes width, so the settings column is narrower. The right panel shows both groups at once, so the tabs only separate settings.

Assumptions to check
Walmart and Target have no framing rule, so the Frame setting shows “No rule” and cannot be turned on. The sample min and max sizes are placeholders until the channel owners confirm them.
{position} is a number. For a name like main on the first image and pt2 on the rest, set the patterns by position: image 1 gets {asin}.main.jpg and the others get {asin}.pt{position}.jpg.
Public channel product shot rules (background, resolution, framing, size) are locked, with no skip switches, because the handling is fixed. Sizes, patterns and lifestyle defaults per channel are placeholders until the channel owners confirm them.
“Above the lips and below the nose” is written as a crop line that sits below the nose and above the lips. Please confirm that is the intended cut.
Two product shots with the same tag get a number (front, front2) by default. The customer can keep the tag instead, and the preview warns when names then clash.
Created images, videos and captions go to review, the same as other AI generation.
