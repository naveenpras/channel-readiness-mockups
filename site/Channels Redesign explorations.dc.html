Custom channels follow whatever rules the customer sets, so product images are not mandatory. The simple configuration applies one list of operations to every image. Per-image configuration is Post-MVP.
3a Product images, simple or per image Built on 2a. Product images are an asset type like any other and can be removed. Set one list of operations for all images, or set operations and file names per image.
